# サンプルアプリの使い方

[ドキュメント一覧](README.ja.md) · [インストールとモデル配置](getting-started.ja.md) · [SDKを自分のアプリへ組み込む](sdk-guide.ja.md)

付属のSwiftUIアプリはiPhoneとApple Silicon Macで使えます。表示名は **SBV2 Core ML** です。
日本語の文章から音声を生成し、**全文の合成が終わってから再生**します。
LLM・マイク・ASRの設定は不要です。

## 最初の読み上げ

Xcodeでの起動とモデルファイルの配置は[クイックスタート](getting-started.ja.md)を参照してください。
モデルを用意した後は、次の順に操作します。

1. 画面右上のスライダーアイコンから **モデル設定** を開く。
2. **共通モデル** で `sbv2-coreml-common`、**声モデル** で `sbv2-coreml-jvnv-f1-jp` を選ぶ。
3. **完了** を押して戻り、**モデルを準備** を押す。初回のコンパイル・読み込み・ウォームアップの完了を待つ。
4. 文章欄へ読み上げる日本語を入力する。
5. **生成して再生** を押す。状態が「音声を生成しています。」→「再生中」→「再生完了」と変わる。

共通フォルダを選ぶと内部のBERTと辞書を自動認識します。個々の `.mlpackage` を選ぶ操作ではありません。
サンプルのDocuments直下に上記の名前の2フォルダを置いた場合は、起動時に自動検出します。
iPhoneでは「ファイル」アプリの **このiPhone内 → SBV2 Core ML** からもDocumentsを開けます。
この設定は[Info-iOS.plist](../Examples/Apple/Info-iOS.plist)に明示しています。

## メイン画面の操作

| 表示・操作 | 動作 |
|---|---|
| 右上のスライダーアイコン | モデル設定を開く |
| 文章カード左上の名前 | 読み込んだ声の話者名を表示する |
| 文章カード右上のスタイル | 声モデルのスタイルを選ぶ。準備後に表示される |
| 話者の選択 | 複数話者の声モデルで表示される |
| 文章欄 | 日本語の読み上げ文を入力する。下部に文字数を表示する |
| モデルを選ぶ | 必要なフォルダが未選択のとき、モデル設定を開く |
| モデルを準備 | 選択済みモデルを読み込み、短い発話でウォームアップする |
| 生成して再生 | 入力全文を合成してから再生する |
| 四角の停止アイコン | 合成または再生を停止する |
| 円形の矢印アイコン | 最後に生成した音声を再合成せずに再生する |

JVNVのスタイル表示は「標準」「うれしい」「悲しい」「怒り」「不安」「嫌悪」「驚き」です。
内部のスタイル名はそれぞれNeutral、Happy、Sad、Angry、Fear、Disgust、Surpriseです。
別の声モデルでは、そのモデルが提供するスタイルと話者を表示します。

スタイルや文章を変更した後は **生成して再生** を押します。
円形の矢印は変更前を含めた「最後に生成した音声」の再生なので、新しい文章・スタイルの合成には使いません。
処理中はモデルやスタイルの選択を無効にします。文章を編集しても、進行中の合成内容は変わりません。
停止時、実行中のCore ML呼び出しは完了を待つため、合成のキャンセルに少し時間がかかる場合があります。

## 時間とRTFの読み方

| 表示 | 意味 |
|---|---|
| 生成時間 | 合成開始から、全文のPCMを取得するまでの時間。モデル準備と再生時間は含まない |
| 音声の長さ | 生成した音声の再生時間 |
| RTF | 生成時間 ÷ 音声の長さ。小さいほど高速。0.1なら10秒の音声を約1秒で生成したことを表す |
| 再生中の進捗バー | 音声の再生位置。合成の進捗ではない |

短い挨拶は固定の処理時間の影響を受け、通常文よりRTFが高くなる場合があります。
モデル準備や未使用の入力長に対する初回推論にも時間がかかります。
[実測条件と検証記録](verification.ja.md)も参照してください。

## 声を追加・変更する

1. [変換ガイド](conversion.ja.md)で作った互換性のある声フォルダを端末へ配置する。
2. モデル設定の **声モデル** で新しいフォルダを選ぶ。
3. **モデルを準備** を押し直し、話者・スタイルを選んで生成する。

同じ共通BERTと辞書を使えます。声フォルダを選び直すと、前の生成済み音声と時間表示をクリアします。
フォルダピッカーでの選択とURL取得先は、このサンプルでは再起動をまたいで保存しません。
再起動後は必要に応じて選び直します。Documents内の既定名のフォルダは自動検出します。

## URLから取得する

モデル設定の **URLからモデルを取得** を開き、共通モデルか声モデルを選び、
配布者の **HTTPSの `download.json` URL** を入力して **ダウンロード** を押します。
共通モデルを取得すると辞書も認識します。取得後に **モデルを準備** を押します。
Webページや圧縮アーカイブのURLはこの欄で使えません。公開URLが確定するまではローカルフォルダを選んでください。

## サンプルの構成

[SBV2Demo.swift](../Examples/Apple/SBV2Demo.swift)の `DemoState` がモデル準備・合成・状態表示を管理し、
`AudioPlayer` が44.1 kHz・モノラルのFloat32音声を1つのバッファで再生します。
サンプルは`synthesize`を使い、再生中の追加合成や再生残り時間に応じた補充は行いません。
長文はSDK内部でモデル容量に合わせて分割される場合がありますが、全区間が揃ってから再生します。

このGUIにはWAV保存ボタンはありません。保存したい場合は[WAV出力CLI](getting-started.ja.md)か
[SDKのWAV生成例](sdk-guide.ja.md)を使います。
初期化失敗や音が出ない場合は[トラブルシューティング](troubleshooting.ja.md)を参照してください。
