# 検証記録

## 2026-09-28〜29の配布準備時に確認したこと

- Swift PackageのReleaseビルド、Swiftテスト7件、iPhone／MacサンプルのReleaseビルド。
- Python 3.11.9でwheelのインストール、CLI起動、Pythonテスト7件。
- JVNVのSafetensorsからの変換、波形比較、多機能モデル化の前後比較。
- KanonのAIVMからの変換。埋め込み設定・スタイル・ライセンスを使用し、Python環境にONNX／ONNX Runtimeがない状態で成功。
  この声は変換確認用で、配布サンプルには含めていません。
- AivisHub公式APIでのメタデータ照会。AIVMXのみの入力は拒否。
- 既存の変換済みFP32 BERTを使ったiPhone／Macの合成。
  `build-bert`の一時出力・相対パス処理はテスト済みですが、このラッパーでの全BERT再変換は再実行していません。

## 速度

JVNV F1 JP-Extra、Releaseビルド、共通FP32 BERT、混合精度の固定長Decoder、seed `20260928`で測定しました。
再生、マイク、ASR、LLMは含みません。両端末のthermal stateはfair (`1`)でした。
声モデルの計算設定はCPU＋Neural Engineです。全演算がANEに配置されたことを示す測定ではありません。

| 入力 | 音声長 | iPhone 17 Pro RTF | Apple M2 Mac／24 GB RTF |
|---|---:|---:|---:|
| 通常文・ウォーム後1回目 | 3.332秒 | 0.105 | 0.177 |
| 同じ文章・次の実行 | 3.297秒 | 0.090 | 0.146 |
| 2文 | 3.170秒 | 0.111 | 0.206 |
| Happyスタイル | 2.299秒 | 0.140 | 0.208 |

繰り返し測定の中央値ではなく、動作確認時の個々の値です。Macでは別のコンパイル・変換処理も動いていました。
容量上限による追加分割はこれらの入力では発生していません。
[iPhoneの生データ](verification/iphone-smoke.json)、[Macの生データ](verification/macos-smoke.json)にOS版などを記録しています。

初回のモデル準備はiPhoneで18.99秒、Macで25.79秒。
その後の最初の0.824秒の挨拶の合成は、それぞれ7.50秒、10.39秒かかりました。
初回コンパイルと初回推論を含むため、ウォーム後のRTFとは分けて扱います。
サンプルの「準備・ウォームアップ」で短い発話を事前に実行しますが、新しい入力長の準備まで全て完了するわけではありません。

## 数値精度とサイズ

JVNVの固定した合成入力に対する検証結果です。

| 比較 | 結果 |
|---|---|
| FP32の合成経路とPyTorch | 波形SNR 94.80 dB、最大絶対誤差0.000006294 |
| 固定長の混合精度DecoderとPyTorch | CPUで約36.9 dB |
| FP32 DecoderとPyTorch | 検証した長さで111 dB超 |
| 多機能モデル化の前後 | 検証した全CPU出力がビット単位で一致 |
| モデル本体のサイズ | 重み共有で899.8 MBから293.6 MBへ縮小 |
| 文脈付きDecoder分割と一括FP32 | MacのCPU／CPU＋ANEで10ケース、全体SNRの最小36.85 dB |

Decoder分割は16／31／64／236／512フレームで確認し、左右13フレームの文脈と末尾補正を含みます。
継ぎ目付近の誤差は[分割検証の記録](verification/jvnv-decoder-windows.json)にあります。
Flowは区間全体を見るため同じ方法で分割していません。

Kanonでは混合精度Decoderが数値基準に届かず、固定長の2関数をFP32で再変換しました。
FP32全体の波形SNRは102.95 dBです。この出力の速度は測定していません。

## この記録から保証しないこと

すべての声・文章・機種でのRTF 0.1、知覚的な音質の完全一致、任意の長文や全スタイルの品質は保証していません。
この準備版では、LLM／ASRとの競合、長時間の熱変化、全対応OS、RAM使用量を網羅していません。
別の声を使ったLocal AIの過去の値を、このサンプルモデルの結果としては扱いません。

再学習・整数量子化・別の声の重みへの置換は行っていません。
公開前には自然文の長母音、無音、接続部、文末、各スタイルを聴き比べます。
GitHub／Hugging Faceの公開URLが確定した後、初期状態の端末からのダウンロードも確認します。
